# CbaExtremo - Guía de Turismo y Aventura en Córdoba

**CbaExtremo** es una plataforma web orientada a promocionar el turismo, la gastronomía y las actividades al aire libre dentro de la provincia de Córdoba. Ofrece una guía interactiva y responsiva para usuarios que buscan experiencias extremas y aventuras en la región.

---

## 🌐 Sitio Desplegado

El proyecto se encuentra desplegado en Vercel y se puede acceder a través de la siguiente URL:

* **Vercel:** [https://cba-extremo.vercel.app](https://cba-extremo.vercel.app)

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica de las páginas.
* **CSS3 / SASS:** Estilizado modular utilizando variables, anidamiento y parciales.
* **Bootstrap 5.3:** Grid responsivo, componentes y utilidades.
* **Font Awesome & Google Fonts:** Tipografías e iconografía.

---

## ⚙️ Cómo Compilar los Estilos SASS

El proyecto utiliza SASS (SCSS) para la gestión y modularización de los estilos CSS.

### Prerrequisitos

Tener instalado Node.js en tu sistema o la extensión **Live Sass Compiler** en Visual Studio Code.

### Compilación desde la Terminal

1. Abrí la terminal en la raíz del proyecto.
2. Ejecutá el siguiente comando para observar cambios y compilar SASS a CSS en tiempo real:

```bash
sass --watch sass:styles
